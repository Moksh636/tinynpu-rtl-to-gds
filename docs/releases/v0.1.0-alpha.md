# TinyPC-NPU v0.1.0-alpha

This first public alpha release establishes the verified accelerator
foundation for the planned TinyPC-NPU FPGA SoC.

## Included

- Parameterized signed multiply-accumulate unit
- Signed INT8 multiplication
- Signed INT32 accumulation
- Sequential 4x4 matrix-multiplication controller
- Local input and result storage
- Self-checking SystemVerilog testbenches
- Python/NumPy golden model
- Pytest golden-model tests
- Makefile-based regression
- GitHub Actions continuous integration

## Verification Status

The v0.1.0-alpha regression currently verifies:

- 10 directed signed MAC cases
- All 16 outputs of a fixed 4x4 matrix multiplication
- Positive, negative, zero, accumulation, and INT8 boundary behavior
- 4 Python golden-model tests

Expected regression result:

- MAC failures: 0
- Matrix-result mismatches: 0
- Python test failures: 0

## Current Architecture

The baseline accelerator uses one signed MAC datapath. A controller iterates
through all row, column, and inner-product indices required to calculate a
4x4 output matrix.

This implementation prioritizes correctness, observability, and verification
before introducing parallel MAC arrays.

## Known Limitations

This is an early development release.

The following components are planned but are not included yet:

- RISC-V-compatible CPU
- SoC interconnect
- RAM and boot ROM
- Memory-mapped NPU wrapper
- UART
- VGA display
- FPGA bitstream
- OpenLane/OpenROAD physical implementation
- Hardware performance measurements

## Next Milestone

The next release will focus on randomized hardware-versus-golden-model
checking, assertions, functional coverage, and a memory-mapped accelerator
interface.
