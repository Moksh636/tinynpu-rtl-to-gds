# TinyPC-NPU v0.2.0-alpha

This release hardens verification of the standalone TinyNPU accelerator. It
adds deterministic hardware-versus-model testing, assertions, functional
coverage, strict lint, synthesis checks, and expanded engineering documents.

## Added

- Parameterized matrix dimension, data width, accumulator width, and address width
- Python vector generator with configurable case count and random seed
- Five directed matrix cases
- Twenty-five seeded randomized matrix cases by default
- Result-by-result RTL comparison against Python golden values
- Simulation timeout and busy-observation checks
- Protocol and progress assertions
- Functional coverage counters with enforced closure goals
- Verilator `-Wall` lint target
- Yosys synthesizability-check target
- Unified `make check` release gate
- Architecture, microarchitecture, verification, and case-study documents

## RTL Hardening

- Explicitly sign-extended MAC products before accumulation
- Explicitly sized parameterized matrix-index calculations
- Separated resetless matrix storage from asynchronously reset controller state
- Preserved the existing external core protocol and result behavior

## Known Limitations

- The accelerator is not memory mapped.
- The Python verification model remains fixed at 4x4 INT8/INT32.
- There is no CPU, interconnect, RAM, ROM, UART, VGA, firmware, or FPGA top level.
- There are no FPGA utilization/timing measurements.
- There is no placed-and-routed ASIC result.
