# TinyPC-NPU v0.4.0-alpha

v0.4.0-alpha introduces the first system-level fabric around the verified
TinyNPU accelerator: a CPU-facing request/response bus, boot ROM, program/data
RAM, and an APB3 bridge to the accelerator.

## System memory map

- `0x0000_0000`-`0x0000_0FFF`: 4 KiB boot ROM
- `0x1000_0000`-`0x1000_3FFF`: 16 KiB program/data RAM
- `0x4000_0000`-`0x4000_0FFF`: TinyNPU MMIO
- `0x4000_1000`-`0x4000_3FFF`: reserved UART/timer/VGA windows

See `docs/system_memory_map.md` for the complete contract.

## Added RTL

- `rtl/tinypc_boot_rom.sv`
- `rtl/tinypc_ram.sv`
- `rtl/tinypc_interconnect.sv`

The interconnect permits one outstanding CPU request, returns a one-cycle
response, and translates TinyNPU transactions into APB3 setup/access phases.

## Error handling

The fabric rejects:

- unaligned accesses;
- boot-ROM writes;
- unmapped and not-yet-implemented windows;
- partial-width TinyNPU writes.

TinyNPU `PSLVERR` responses are propagated to the system bus.

## Verification additions

- `tb/tinypc_interconnect_tb.sv`
- `tb/tinypc_npu_bus_tb.sv`
- `tb/data/boot_rom_test.hex`
- `mk/soc.mk`

The interconnect test covers boot-ROM contents, ROM write protection, full and
byte-strobe RAM writes, region boundaries, alignment faults, unmapped accesses,
NPU decoding, APB bridge stalls, APB error propagation, and partial MMIO write
rejection.

The CPU-style integration test loads both operand matrices through the system
bus, starts TinyNPU through MMIO, polls completion, and checks all 16 INT32
results. Matrix B is an identity matrix, so every expected result is exact and
independent of a second RTL implementation.

## Scope after v0.4

The system fabric and memories are present, but there is still no CPU, firmware,
UART, timer, VGA block, FPGA top-level deployment, or ASIC physical design.
The next implementation milestone is the pipelined RV32I CPU.

## Verified release gate

The local `make clean && make check` gate passed on the project Fedora
toolchain. The run verified:

- 10/10 directed MAC cases;
- all 16 directed core outputs;
- 30/30 deterministic directed/randomized matrix cases with 480 checked results;
- 4/4 Python golden-model tests;
- TinyPC boot-ROM, RAM, byte-strobe, boundary, alignment, and decode behavior;
- NPU APB bridge stalls and error propagation;
- CPU-style loading, start, polling, and all 16 signed INT32 result reads;
- a second system-bus-controlled NPU computation without reloading operands;
- Verilator lint for the SoC and accelerator;
- Yosys synthesizability checks for the SoC, accelerator, and APB wrapper;
- the complete existing APB smoke/computation regression, assertions, and coverage.

GitHub Actions remains the independent clean-environment confirmation when the
v0.4 branch is pushed.
